# ことば Live

外国語の音声を聞き取り、発話が確定した区切りごとに日本語へ翻訳する、スマホ対応のWebツールです。

## GitHub Pagesで公開

1. GitHubで `kotoba-live` というPublicリポジトリを作成します。
2. このフォルダー内の `index.html`、`style.css`、`app.js`、`.nojekyll`、`README.md` をリポジトリのルートにアップロードします。ZIP自体をアップロードするのではなく、展開した中身をアップロードしてください。
3. リポジトリの **Settings → Pages** を開きます。
4. **Build and deployment → Source** を **Deploy from a branch** にし、ブランチを **main**、フォルダーを **/ (root)** にして保存します。
5. Pages画面に表示される公開URLをスマホで開きます。通常は `https://ユーザー名.github.io/kotoba-live/` です。

公式手順: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 使い方

相手の言語を選択し「聞き取りを開始」を押して、マイクの使用を許可します。画面を開いたまま会話してください。音声認識が利用できない場合はテキスト入力を使用できます。履歴は画面内のメモリだけに保存され、再読み込みすると消えます。

## 利用条件と制限

- HTTPS、インターネット接続、音声認識に対応したブラウザが必要です。対応状況は端末とブラウザに依存します。
- 音声認識にはブラウザの認識サービスを使用し、認識テキストはMyMemory翻訳サービスに送信します。機密情報の入力は控えてください。
- MyMemoryには利用上限があります。通信障害や上限超過は画面内に表示します。
- 自動言語判定、他アプリの音声の直接取得、バックグラウンドでの継続利用には対応していません。
- 日本語の読み上げは、聞き取り停止中に完了した翻訳で動作します。
- APIキーや秘密情報を設定する必要はありません。将来APIキーを追加する場合、公開JavaScriptに書き込まないでください。
